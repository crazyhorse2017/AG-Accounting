If you owe more than you can pay, file your return on time anyway.

The failure-to-file penalty is generally 5% of the unpaid tax for each month the return is late. The failure-to-pay penalty is generally 0.5% per month. Both are capped at 25%, but the difference adds up fast.

Then:

1. Pay as much as you can.
2. Look into an IRS payment plan; many can be set up online.
3. Call us if you’d like help choosing an option.
